# CXR-Age-Benchmark

An independent reimplementation of chest X-ray (CXR) age estimation with convolutional neural networks (CNNs), following the approach of Ieki et al. (*Communications Medicine*, 2022). The code trains an image-to-age regression model on the NIH ChestX-ray dataset.

## Overview

Ieki et al. showed that a deep learning model can estimate chronological age from a chest radiograph. To our knowledge, the authors did not release their complete training code. This repository is therefore an **independent reimplementation**, not the official code, and it is not affiliated with the original authors.

This repository implements the following components from scratch:

- **Data preprocessing**: metadata parsing, patient-wise train/validation/test splitting, leakage checks, and dataset statistics.
- **Model training**: an ImageNet-pretrained CNN backbone with a regression head, trained with an L1 loss.
- **Evaluation**: MAE, MSE, RMSE, R², and Pearson correlation on the validation set, with diagnostic plots.

Implementation details that the original paper does not specify (for example the number of epochs, the regression head, and the optimizer settings) are our own choices and may differ from the original work.

### Scope and current status

- The code supports ten backbone architectures (see [Model architecture](#model-architecture)). **A systematic benchmark across all of them has not been completed, and no benchmark results are reported in this repository.**
- Training and validation use NIH ChestX-ray only. Evaluation on external data (for example JSRT) is **not** implemented.
- `train_DNN.py` evaluates on the validation split only. The test split is generated by the preprocessing step, but no test-set evaluation script is provided yet.

## Environment

The repository does not pin package versions, and the exact versions used have not been recorded. The scripts import the following packages:

- Python 3
- PyTorch and torchvision
- NumPy, pandas, SciPy, scikit-learn
- Pillow
- matplotlib, seaborn
- tqdm

A CUDA-capable GPU is recommended for training; the code falls back to CPU if none is available. Backbones are created with the `pretrained=True` argument of torchvision, which is deprecated in recent torchvision releases. If you use a recent version, you may need to switch to the `weights=` argument.

## Data preparation

1. Download the [NIH ChestX-ray14 dataset](https://nihcc.app.box.com/v/ChestXray-NIHCC) and place the following in `NIH_data/`:
   - the `images/` folder, with all image files directly inside it (no extra sub-directory levels);
   - `Data_Entry_2017_v2020.csv`;
   - `train_val_list.txt` and `test_list.txt`.

2. Run preprocessing:

   ```bash
   python preprocess_nih.py --data_root ./NIH_data
   ```

   Options:

   | Argument | Description | Default |
   | --- | --- | --- |
   | `--data_root` | Directory containing `images/` and the metadata files. Outputs are written to `processed/` and `reports/` inside it. | required |
   | `--val_size` | Fraction of train/val patients held out for validation. | `0.083` |
   | `--random_state` | Random seed for the patient split. | `42` |

   The script keeps the official NIH `test_list.txt` as the test set and splits the patients in `train_val_list.txt` into training and validation sets. The split is made **by patient**, so no patient appears in more than one set, and a leakage check is run. It also writes dataset statistics, a distribution plot, and a `config.json` summary. Note that `train_DNN.py` does not read `config.json`.

## Training

```bash
python train_DNN.py --data_root ./NIH_data
```

`--data_root` must point to the same directory used for preprocessing.

| Argument | Description | Default |
| --- | --- | --- |
| `--data_root` | Preprocessed data directory | required |
| `--save_dir` | Output directory for checkpoints and plots | `./checkpoints` |
| `--backbone` | Backbone architecture | `resnet50` |
| `--img_size` | Input image size | `320` |
| `--dropout` | Dropout rate in the regression head | `0.5` |
| `--batch_size` | Batch size | `32` |
| `--num_epochs` | Number of epochs | `100` |
| `--lr` | Learning rate | `1e-4` |
| `--weight_decay` | Adam weight decay | `1e-5` |
| `--num_workers` | Data loading workers | `4` |

The original paper does not state the number of training epochs, so this value is left to the user. If training is slow, a smaller value such as 50 can be used for a first run.

### Running on a SLURM cluster

`run_nih_train.slurm` is an example job script. Edit the `--mail-user` address, the conda environment name, and the resource requests for your cluster. Paths and hyperparameters can be overridden at submission time:

```bash
sbatch --export=ALL,REPO_DIR=/path/to/repo,DATA_ROOT=/path/to/NIH_data,BACKBONE=resnet50 run_nih_train.slurm
```

By default `DATA_ROOT` is `<REPO_DIR>/NIH_data`. The script requires `processed/train_set.csv` and `processed/val_set.csv` to exist before it launches training.

### Outputs

Written to `--save_dir`:

- `best_model.pth`: checkpoint with the lowest validation MAE;
- `checkpoint_epoch_N.pth`: checkpoints saved every 10 epochs;
- `training_history.json` and `training_history.png`;
- `predictions_epoch_N.png`: validation scatter plots, saved every 5 epochs;
- `best_model_metrics.json` and `best_model_analysis.png`: metrics and diagnostic plots for the best epoch.

## Model architecture

**Backbone.** An ImageNet-pretrained CNN with its original classification layer removed. Supported options for `--backbone`:

`resnet50`, `resnet101`, `resnet152`, `densenet121`, `densenet169`, `densenet201`, `efficientnet_b0`, `efficientnet_b3`, `vgg16`, `vgg19`

**Regression head.** A multilayer perceptron on the pooled backbone features:

`Dropout(p)` → `Linear(F, 512)` → `ReLU` → `Dropout(p)` → `Linear(512, 256)` → `ReLU` → `Dropout(p/2)` → `Linear(256, 1)`

where `F` is the backbone feature dimension and `p` is `--dropout`.

**Training setup.**

- Loss: L1 (mean absolute error).
- Optimizer: Adam, with gradient-norm clipping at 1.0.
- Scheduler: `ReduceLROnPlateau` on validation MAE (factor 0.5, patience 5).
- Model selection: the epoch with the lowest validation MAE.
- Input: grayscale images converted to 3 channels, resized to `img_size` × `img_size`, normalized with ImageNet statistics.
- Training augmentation: random rotation (±20°), random translation (up to 10%), and brightness and contrast jitter. Validation images are not augmented.
- Samples with an age outside 0–120 are filtered out.

## Evaluation metrics

Computed on the validation set after each epoch, and in full for the best epoch:

- Mean absolute error (MAE, in years)
- Mean squared error (MSE)
- Root mean squared error (RMSE, in years)
- Coefficient of determination (R²)
- Pearson correlation coefficient (r) and its p-value
